# GomiDev
My Official Website !! Explore all the content I have created under the name of GomiDev

A terminal-style static site (black background, white text, no images: everything is characters),
in Spanish and English, hosted on GitHub Pages and refreshed automatically every day.

## Structure

```
index.html, games.html, software.html,     one HTML shell per section; content is rendered by JS
books.html, about.html, media.html, 404.html
assets/css/style.css                       all styles
assets/js/i18n.js                          ALL site text (ES/EN) + the fake loading commands per page
assets/js/app.js                           rendering, loading animation, language switch
assets/ascii/banner.txt                    "GOMIDEV" banner (hand-made, ANSI Shadow figlet style)
assets/ascii/logo.txt                      logo.png converted to ASCII (regenerated by the updater)
config.json                                accounts, manual games/software/books entries
data/content.json                          generated by the updater, do not edit by hand
scripts/update_content.py                  fetches GitHub / itch.io / YouTube / Instagram -> data/content.json
scripts/ascii_art.py                       image -> ASCII converter (used for logo, covers, thumbnails)
.github/workflows/deploy.yml               daily sync + deploy to GitHub Pages
```

## Editing content

- **Texts (bio, about me, section descriptions)**: `assets/js/i18n.js`, both `es` and `en`.
- **Loading animation commands**: `LOADERS` at the bottom of `assets/js/i18n.js`.
- **Accounts**: `config.json` → `itch.user`, `youtube.handle` (e.g. `"@GomiDev"`) or `youtube.channel_id`,
  `instagram.user`, `amazon.author_url`.
- **Games**: any repo listed in `github.game_repos` or tagged with the GitHub topic `game` is a game.
  Everything else (except forks and `github.exclude`) is software. Add the topic `wip` to a repo to mark
  it "in development". Entries in `config.json` → `games` are merged with the automatic ones
  (matched by `repo`, `itch` URL or `title`) so you can add an itch.io link, website, status or a
  bilingual description.
- **Books**: `config.json` → `books`, with `status` `"writing"` or `"published"` and the Amazon `url`.
  (Amazon has no public API for author pages, so books are listed manually.)
- **Logo**: replace `logo.png`; the updater re-converts it to ASCII.

## Automatic updates

`.github/workflows/deploy.yml` runs on every push to `main`, every day at 06:17 UTC and on demand
(Actions → "Update content & deploy" → Run workflow). It fetches the latest content, converts images
to ASCII, commits `data/content.json` if anything changed and deploys the site.

| Source    | What it needs                                                                 |
|-----------|-------------------------------------------------------------------------------|
| GitHub    | nothing (uses the built-in `GITHUB_TOKEN`)                                    |
| YouTube   | `youtube.handle` or `youtube.channel_id` in `config.json` (public RSS feed)   |
| itch.io   | repository secret `ITCH_API_KEY` (itch.io → Settings → API keys)              |
| Instagram | repository secret `INSTAGRAM_TOKEN` (see below)                               |

Instagram only exposes posts through the official API: the account must be a **Professional**
(Creator or Business) account, and you need an access token from a Meta app using
"Instagram API with Instagram Login". Long-lived tokens last 60 days, so they need to be renewed
and the secret updated.

## One-time GitHub setup

1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Settings → Secrets and variables → Actions: add `ITCH_API_KEY` / `INSTAGRAM_TOKEN` when available.
3. Push to `main`. The site will be at `https://grojman.github.io/GomiDev/`
   (or at `https://grojman.github.io/` if the repo is renamed to `Grojman.github.io`).

## Running locally

```bash
pip install -r scripts/requirements.txt
python scripts/update_content.py         # optional: refresh data/content.json
python -m http.server 8000               # then open http://localhost:8000
```

The pages load `data/content.json` with `fetch`, so open them through a local server, not `file://`.

Convert any image to ASCII:

```bash
python scripts/ascii_art.py some-image.png --cols 60
```
